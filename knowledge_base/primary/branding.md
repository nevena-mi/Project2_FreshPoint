# Branding

- Primary color: `#0B5563` (deep teal) — main brand color, used for headers/accents; passes WCAG AA (7:1) against white
- Secondary color: `#2E8B7D` (muted green-teal) — supporting color for secondary elements, links, highlights
- Accent color: `#F2A65A` (warm amber) — small, deliberate accent for CTAs or callouts; sits opposite blue/green on the wheel so it draws the eye without clashing
- Neutral dark: `#1B2A2E` (near-black teal-charcoal) — body text on light backgrounds; passes WCAG AAA against white
- Neutral light: `#F4F7F6` (off-white with a cool tint) — background color, easier on the eyes than pure white

## Accessibility notes
- Deep teal (`#0B5563`) on off-white (`#F4F7F6`) gives strong contrast for headers and body text.
- Avoid pairing the accent amber (`#F2A65A`) with the secondary green-teal directly as text-on-background — the contrast is too low for body copy; use amber only for small UI elements (buttons, icons), never for paragraph text.
- If used in diagrams: keep amber reserved for the one thing you want to highlight, so it doesn't compete with the teal/green as the dominant palette.
